# cal-number-days

開始日と終了日を指定して、2つの日付の間が何日あるかを確認できるReactアプリです。

## 概要

`cal-number-days` は、日付を1日・1か月・1年・5年単位で増減しながら、指定した期間の日数を計算するためのシンプルなツールです。

## 主な機能

- 開始日と終了日の表示
- 2つの日付の差分日数の計算
- 最初の日を日数に含めるかどうかの切り替え
- 開始日をCookieに保存
- 今日の日付へのリセット
- 日付または日数をボタン操作で増減

## 必要な環境

- Node.js
- npm

## セットアップ

依存パッケージをインストールします。

```bash
npm install
```

## 開発サーバーの起動

```bash
npm run dev
```

起動後、ターミナルに表示されるURLをブラウザで開いてください。

## ビルド

本番用ファイルを作成します。

```bash
npm run build
```

## プレビュー

ビルドした内容をローカルで確認します。

```bash
npm run preview
```

## 使用技術

- React
- Vite
